# Killfeed icons

The WebP files in this directory are the original Counter-Strike killfeed
icons presented by the [Counter-Strike Wiki](https://counterstrike.fandom.com/wiki/Kill_Feed):
headshot, penetration, flash assist, blind kill, no-scope, smoke kill,
domination, and revenge.

Counter-Strike game artwork belongs to Valve Corporation. The wiki page and
its community text are published under CC BY-SA unless otherwise noted.
